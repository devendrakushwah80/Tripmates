## Backend

The production Core PHP + MySQL API backend is isolated in `tripmates_backend/`.

See `tripmates_backend/README.md` for:
- XAMPP/WAMP/LAMP setup
- MySQL schema import
- auth and verification endpoints
- secure upload folders
- Flutter API base URL setup
- Postman test collection
